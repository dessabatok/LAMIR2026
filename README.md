# Investigative Study of Music Emotion Recognition Using Dynamic Linear Models and Principal Component Analysis

This repository contains the code developed for the study *"Investigative Study of Music Emotion Recognition Using Dynamic Linear Models and Principal Component Analysis."*

The project investigates how emotions conveyed by music can be modeled from audio-derived features. Principal Component Analysis (PCA) is used to reduce dimensionality and extract the main sources of variation in the acoustic data, while Dynamic Linear Models (DLMs) capture how emotional dimensions evolve over time.

## Contents

- Data preprocessing and feature extraction
- Dimensionality reduction with PCA
- Dynamic Linear Model fitting and analysis
- Scripts to reproduce the figures and results presented in the study
